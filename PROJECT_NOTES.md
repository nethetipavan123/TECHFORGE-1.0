# Project Notes

## Problem
EV charging networks need to balance charging cost, waiting time, charger availability, vehicle requirements, and grid capacity.

## Prototype features
- Dashboard overview and illustrative metrics
- Station search and ranking using sample price/wait/distance values
- Browser GPS permission flow with illustrative station pins
- Basic battery target, charger power, tariff, and grid-capacity calculator
- Car/SUV, electric bus, and light-EV sample presets
- Sample session history and analytics tables

## Validation needed
- Confirm official challenge scope and constraints.
- Use a trustworthy dataset and document its source/license.
- Add a proper scheduler that considers multiple vehicles, time slots, charger constraints, departure deadlines, and site power limits.
- Add automated tests and compare with a baseline.
- Label all estimates and assumptions clearly.
